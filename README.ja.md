# fix-scansnap

スキャンしたPDF文書の縦横比を補正するシンプルなBashスクリプトです。

ScanSnapを含む一部のドキュメントスキャナーでは、スキャン設定や原稿の扱い方によって、縦横比が歪んだPDFが生成されることがあります。このツールは、ImageMagickを使用してスキャン済みPDFページの縦方向の倍率を補正します。

固定パーセントによる補正と、標準的な用紙の縦横比への自動調整に対応しています。

## 機能

- スキャンしたPDF文書の縦方向の歪みを補正
- 元のページ幅を維持したままページの高さを調整
- すべてのページに固定の縦方向倍率を適用
- 各ページをA4またはB5の縦横比に自動調整
- 複数ページのPDF文書に対応
- 元のファイルを上書きせず、補正後のPDFを保存

## 必要な環境

- Bash
- ImageMagick 7（`magick`コマンド）
- Ghostscript（ImageMagickでPDFを処理するために必要）

### macOS

Homebrewを使用して依存パッケージをインストールします。

```bash
brew install imagemagick ghostscript
```

### Ubuntu / Debian

ImageMagick 7とGhostscriptをインストールし、`magick`コマンドが使用できることを確認してください。

> **注意:** ImageMagickの環境によっては、セキュリティポリシーによりPDFの読み書きが制限されています。使用する環境でPDF処理を許可する必要があります。

## インストール

```bash
git clone https://github.com/skyhobbit/fix-scansnap.git
cd fix-scansnap
chmod +x fix-scansnap.sh
```

## 使い方

### 固定パーセントで補正する

```bash
./fix-scansnap.sh -p 69.20 scan.pdf
```

この例では、幅を変更せずに各ページの高さを元の69.20%に縮小します。

### A4の縦横比に自動補正する

```bash
./fix-scansnap.sh -s a4 scan.pdf
```

各ページを個別にA4用紙（210 × 297 mm）の縦横比へ調整します。

### B5の縦横比に自動補正する

```bash
./fix-scansnap.sh -s b5 scan.pdf
```

各ページを個別にB5用紙（182 × 257 mm）の縦横比へ調整します。

## 出力

補正後のPDFは、入力ファイルと同じディレクトリに、ファイル名へ`_corrected`を追加して保存されます。

```text
scan.pdf
scan_corrected.pdf
```

元のファイルは変更されません。ただし、同じ名前の出力ファイルがすでに存在する場合は上書きされる可能性があります。

## 仕組み

このスクリプトはImageMagickを使用し、300 DPIでスキャン済みPDFのページを処理します。

固定パーセントモード（`-p`）では、指定された縦方向倍率をPDFのレンダリングに直接適用します。

用紙サイズモード（`-s`）では、次の処理を行います。

1. PDFの各ページをPNG画像としてレンダリングします。
2. 各ページの幅と高さを測定します。
3. 選択した用紙の縦横比を基に目標の高さを計算します。
4. 幅を維持したまま、各ページを縦方向にリサイズします。
5. 補正後のページ画像を1つのPDFに結合します。

縦方向倍率は次の式で計算されます。

```text
目標の高さ = 現在の幅 × 用紙の高さ / 用紙の幅

縦方向倍率（%） = 目標の高さ / 現在の高さ × 100
```

各ページは個別に処理されるため、元の寸法が異なるページを含む複数ページの文書も補正できます。

## 制限事項

- PDFページは300 DPIでラスタライズされます。検索可能なテキスト、ベクターグラフィックス、その他のPDFメタデータは保持されない可能性があります。
- ページ内の個別のオブジェクトやコンテンツ領域ではなく、ページ全体を調整します。
- 用紙サイズによる自動補正では、スキャンしたページが選択した用紙と同じ縦横比になることを前提としています。
- 用紙サイズモードは、縦向きのA4およびB5の縦横比のみに対応しています。
- ページ境界の自動検出、余白のトリミング、傾き補正は行いません。
- ページ数が多いPDFや高解像度のPDFの処理には、多くのメモリと一時ディスク容量が必要になる場合があります。
